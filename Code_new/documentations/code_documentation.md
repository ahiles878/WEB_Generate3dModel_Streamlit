# Подробное описание кода приложения генерации 3D-моделей

## Общая архитектура приложения

Приложение представляет собой веб-интерфейс для генерации 3D-моделей на основе текстовых описаний или загруженных изображений. Оно использует Streamlit для веб-интерфейса, ComfyUI для генерации изображений и 3D-моделей, OpenRouter для улучшения текстовых промптов и OctoPrint для управления 3D-печатью.

## Структура кода

### 1. Конфигурационные настройки
```python
# Configuration settings loaded from secrets.toml
try:
    COMFYUI_URL = st.secrets["COMFYUI_URL"]
    OPENROUTER_API_KEY = st.secrets["OPENROUTER_API_KEY"]

    OCTOPRINT_URL = st.secrets.get("OCTOPRINT_URL")

except:
    # Fallback values for testing
    COMFYUI_URL = "http://localhost:8188"
    OPENROUTER_API_KEY = "test-key"

    OCTOPRINT_URL = "http://192.168.1.100:5000"
    OCTOPRINT_API_KEY = "test-key"
```

### 2. Клиенты для внешних сервисов

#### OpenRouterClient
Класс для работы с OpenRouter API, который используется для улучшения текстовых промптов:
- Инициализируется с API ключом и моделью
- Загружает системный промпт из `system_prompt.md` или `initial_sysprompt.md`
- Метод `enhance_prompt()` улучшает текстовый запрос пользователя

#### ComfyUIClient
Класс для работы с ComfyUI API, который используется для генерации изображений и 3D-моделей:
- Поддерживает подключение к ComfyUI серверу
- Проверяет соединение при инициализации
- Загружает workflow из JSON файлов
- Загружает изображения в ComfyUI
- Запускает workflow и отслеживает прогресс
- Извлекает сгенерированные изображения и 3D-модели
- Поддерживает таймауты для генерации изображений и 3D-моделей

#### OctoPrintClient
Класс для отправки моделей на печать через OctoPrint:
- Загружает модель из URL в OctoPrint
- Начинает печать модели
- Обрабатывает ошибки при печати

#### ImageEnhancementClient
Новый класс для улучшения сгенерированных изображений:
- Использует OpenRouter API для улучшения изображений
- Принимает URL изображения, оригинальный промпт и запрос на улучшение
- Возвращает улучшенный промпт для перегенерации изображения

### 3. Основные функции генерации

#### generate_images_from_text(prompt: str, client: ComfyUIClient)
Функция генерирует 4 изображения из текстового промпта:
- Улучшает промпт с помощью OpenRouterClient
- Загружает workflow для генерации изображений
- Запускает генерацию и ожидает завершения
- Извлекает URL сгенерированных изображений

#### generate_3d_from_image(client: ComfyUIClient, image_url: str = None, image_file_path: str = None)
Функция генерирует 3D-модель из изображения:
- Загружает workflow для 3D генерации
- Загружает изображение в ComfyUI при необходимости
- Запускает генерацию 3D-модели
- Извлекает URL сгенерированной модели

### 4. Интерфейс Streamlit

#### Режимы работы
Приложение поддерживает два режима:
1. **С нуля**: Создание 3D моделей из текстовых описаний
2. **Загрузка изображения**: Конвертация загруженных изображений в 3D модели

#### Основной интерфейс
- Панель навигации с выбором режимов
- Проверка подключений к внешним сервисам
- Отображение прогресса генерации
- Возможность выбора сгенерированных изображений
- Управление печатью через OctoPrint

#### Функциональность улучшения изображений
- После выбора изображения пользователю предлагаются три опции: "Продолжить", "Перегенерировать" и "Изменить"
- Кнопка "Продолжить" позволяет использовать выбранное изображение для генерации 3D-модели
- Кнопка "Перегенерировать" создает новые изображения на основе исходного промпта
- Кнопка "Изменить" позволяет пользователю ввести запрос на улучшение изображения
- Приложение использует ImageEnhancementClient для генерации улучшенного промпта
- Система перегенерирует изображения на основе улучшенного промпта

## Особенности реализации

1. **Обработка секретов**: Приложение использует безопасное хранение API ключей и URL сервисов в файле secrets.toml с fallback значениями для тестирования

2. **Обработка ошибок**: Код включает обработку ошибок при подключении к внешним сервисам и генерации контента

3. **Прогресс-отслеживание**: Реализованы прогресс-бары и динамические сообщения о прогрессе генерации

4. **Управление состоянием**: Используется Streamlit session_state для управления состоянием приложения между перезапусками

5. **Улучшенная функциональность**: Реализована новая функция улучшения изображений с тремя опциями выбора действия, позволяющая пользователю вносить правки в сгенерированные изображения до генерации 3D-модели

Приложение полностью готово к использованию и предоставляет удобный интерфейс для генерации 3D-моделей с возможностью улучшения промптов изображений.
