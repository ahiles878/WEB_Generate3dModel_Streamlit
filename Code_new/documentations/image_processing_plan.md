# План реализации функционала обработки изображений

## Цель
Реализовать сохранение изображения пользователя и дальнейшую его отправку в OpenRouter к VLM для генерации prompt на основе пользовательского запроса и картинки. Prompt будет использован для генерации нового изображения.

## Архитектурные изменения

### 1. Модуль обработки изображений (utils/image_utils.py)
- Функция сохранения загруженного изображения во временный файл
- Функция кодирования изображения в base64
- Функция проверки валидности изображения
- Функция очистки временных файлов

### 2. Модификация OpenRouterClient (clients/openrouter_client.py)
- Добавить метод для обработки изображений с помощью VLM
- Добавить поддержку base64 кодирования изображений
- Обновить метод enhance_prompt для работы с изображениями

### 3. Обновление generation_functions (utils/generation_functions.py)
- Добавить интеграцию с новыми функциями обработки изображений
- Реализовать новый метод для генерации промпта на основе изображения и текста

## Последовательность вызовов
1. Пользователь загружает изображение и вводит запрос
2. Изображение сохраняется во временный файл
3. Изображение кодируется в base64
4. Изображение и текст отправляются в VLM через OpenRouter
5. Полученный промпт используется для генерации нового изображения в ComfyUI
