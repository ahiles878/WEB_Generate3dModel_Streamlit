## Логика:
    1. В чате web-сайта пользователя встречает название и поле для ввода. В поле для ввода пользователь может загрузить картинку и подпись к ней или только текст.
    2.1 Если пользователь загрузил и картинку и текст к ней (или без текста), то запрос пользователя и editing_prompt посылается в VLM(OPENROUTER_MODEL) чтобы создать prompt для генерации изображений пригодных для 3D моделирования на основе system_prompt(в папке prompts), текста(при наличии) и картинки.
    2.1.1 Улучшенный запрос вставляется в ноду положительного запроса в OnlyGenImage.json и этот workflow отправляется в ComfyUI(по адресу из папки secrets) для генерации картинки
    2.1.2 После генерации изображения оно передается напрямую в ноду загрузки изображений в OnlyGenModel.json и этот workflow отправляется в ComfyUI для генерации 3D модели
    2.1.3 Сгенерированная 3D модель выводится в чат пользователю с возможностью ее скачать
    2.2 Если пользователь написал только текст, то запрос пользователя посылается в VLM(OPENROUTER_MODEL) чтобы создать prompt для генерации изображений пригодных для 3D моделирования на основе system_prompt(в папке prompts).
    2.2.1 Улучшенный запрос вставляется в ноду положительного запроса в OnlyGenImage.json, кол-во картинок выбирается равным 4 и этот workflow отправляется в ComfyUI(по адресу из папки secrets) для генерации картинок
    2.2.2 Сгенерированные изображения скачиваются на локальную машину(где выполняется код) и отправляются в чат пользователю для выбора
    2.2.3 Пользователь может: перегенерировать все картинки или выбрать какую-то одну для генерации 3d модели
    2.2.4 Когда пользователь выбрал подходящую картинку, она вставляется в ноду загрузки изображений в OnlyGenModel.json и этот workflow отправляется в ComfyUI для генерации 3D модели
    2.2.5 Сгенерированная 3D модель выводится в чат пользователю с возможностью ее скачать

Все ключи, ссылки и модели находятся в папке secrets.toml. На каждом этапе пользователь может вернуться на предыдущий или начать заново.
